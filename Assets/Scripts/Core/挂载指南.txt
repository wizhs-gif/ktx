================================================================================
                Unity 多场景游戏 完整挂载指南（策划案版）
================================================================================

基于策划案分析，本游戏存在以下关键技术需求：
- 双视角系统：室内第一人称 / 室外第三人称
- 多场景架构：11+ 个独立场景
- NPC条件生成系统：按天数、精神值、物品动态出现
- 37个物品 + 8个物品组 + 组合系统
- 5个时间段 × 7天的时间系统
- 多种小游戏
- 早上上班时间选择UI（8秒倒计时）

================================================================================
二、双视角系统说明
================================================================================

当前 PlayerManager.cs 只支持第一人称（相机作为子物体，鼠标控制旋转）。
室外第三人称需要额外的相机控制逻辑。

两种方案：

方案A（推荐）：一个 PlayerManager 支持双模式
  - 添加 public enum ViewMode { FirstPerson, ThirdPerson }
  - 添加 [SerializeField] private ViewMode viewMode
  - 第三人称时：相机在玩家身后偏上，显示玩家模型
  - 第一人称时：相机在玩家眼部，隐藏玩家模型
  - 每个场景的 Player Prefab 上设置不同的 ViewMode

方案B：两套 Player Prefab
  - Player_FP（第一人称）：用在 Home、OfficeInterior
  - Player_TP（第三人称）：用在其他室外场景
  - 每个场景拖入对应的 Prefab

建议用方案A，代码改动小，统一管理。

注意：Player 的 Tag 必须始终设为 "Player"，NPC 的触发检测依赖这个 Tag。

三、启动场景（MainMenu）
================================================================================

创建一个空 GameObject "GameManager"：

  GameManager (GameObject)
  ├── GameBootstrap.cs
  │     拖入引用：
  │     ├── ItemDatabase.asset
  │     ├── NPCDatabase.asset
  │     ├── GameConfig.asset
  │     ├── GameDataManagerPrefab (可选)
  │     ├── SaveSystemPrefab (可选)
  │     └── InteractSystemPrefab (可选)
  │
  ├── UIManager.cs
  ├── SceneController.cs
  ├── GameFlowManager.cs
  ├── ItemCombineSystem.cs
  │     配置合成配方：
  │     ├── 揉皱的海报 + 照片：血色回忆 → 治疗的消息
  │     └── （后续配方）
  │
  └── TimeManager.cs

  MiniGameRoot (GameObject)
  └── MiniGameManager.cs

这些全部 DontDestroyOnLoad，切场景后保留。


================================================================================
四、地铁场景（Subway）—— 纯UI场景
================================================================================

地铁场景不需要3D世界，是一个纯UI界面。

  Canvas
  └── SubwayUI (GameObject)
        └── SubwayMapUI.cs                 ← 需要新写或用现有 Map/GameManager.cs
              ├── 地铁线路图 Image
              ├── 各站点 Button（五河站、通平苑站等）
              ├── 站点说明 Text（鼠标悬停显示）
              └── 功能：点击站点 → SceneController.Instance.LoadScene("目标场景")

特殊逻辑（策划要求）：
  - 开场前几天，只有特定站点高亮可点，其他站点灰色不可点
  - 第4天开始UI变暗+噪点
  - 第5天开始不可交互，直接出现字幕后自动跳转
  - 这些逻辑需要在 SubwayMapUI 中根据 GameDataManager.Instance.CurrentDay 实现

--------------------------------------------------------------------------------
Home（家）具体配置
--------------------------------------------------------------------------------

  Player 位置：卧室门口（起床位置）

  室内可交互物体：
  ├── 镜子 (交互)                      → 获得物品"镜子"
  ├── 书架 (交互)                      → 获得物品"爻"
  ├── 相机 (交互)                      → 获得物品"蒙尘相机"
  ├── 咖啡机 (交互)                    → 开场引导交互
  ├── 地铁线路图 (交互)                → 开场引导交互
  └── 床 (交互)                        → 结束UI触发点

  室内三选一交互（每天一次）：
  ├── 录入 → 检查图鉴收集状态，根据套组给一次性奖励
  ├── 思考 → 精神值+1，打开组合界面（ItemCombineUI）
  └── 休息 → 精神值-2

  物品组合台：
  └── 思考时打开 ItemCombineUI，拖入物品组合
      已知配方：揉皱的海报 + 照片：血色回忆 → 治疗的消息

  特殊逻辑：
  - 开场剧情时，卧室有虚化特效（没睁眼的感觉）
  - 偏离引导方向时加眩晕UI特效
  - 精神值差分：家的场景根据精神值有2-3个视觉差分

  NPC：无固定NPC（剧情NPC通过事件触发）


--------------------------------------------------------------------------------
OfficeInterior（办公室内）具体配置
--------------------------------------------------------------------------------

  Player 位置：自己工位附近

  室内交互物体：
  └── 工位 (交互，四选一)
        ├── 摸鱼 → 和隔壁工位NPC林悦聊天（对话）
        ├── 工作 → 进入小游戏E（连连看），+60钱
        ├── 放空 → 什么都不做
        └── 看股票 → 进入小游戏F（股票）

  每个活动消耗一个时间段，做完正好下班，+30钱（选工作则+60）

  NPC：
  └── 林霖（隔壁工位，固定出现，摸鱼时触发对话）

  注意：进入办公室是通过办公写字楼的传送点，
        到达后直接进入室内场景，跳过上班时间选择。

十四、精神值差分系统
================================================================================

精神值 0-5 六档，影响：

  1. NPC对话内容不同
  2. 地图外观变化（2-3个差分）
  3. 部分交互点出现/消失
  4. 陵园：树 ↔ NPC 切换
  5. 公园：跑者掉落物品触发
  6. 广场：庙的出现
  7. UI效果（恐怖程度递增）

  实现方式：
  - 各场景物体默认激活/隐藏，由 NPCManager 或场景初始化脚本
    根据 GameDataManager.Instance.Sanity 控制
  - 精神值变化时通过 GameEvents.OnSanityChanged 事件触发刷新

  - 相机在玩家身后偏上
  - 鼠标水平：环绕玩家旋转
  - 鼠标垂直：调整俯仰角（-20°~60°）
  - 移动方向相对相机（WASD控制方向）
  - 角色自动朝移动方向转身

  第三人称参数（Inspector可调）：
  - thirdPersonDistance  → 相机距离（默认4）
  - thirdPersonHeight   → 相机高度（默认2）
  - thirdPersonLookOffset → 看向点偏移（默认1.5）
  - orbitSmoothSpeed    → 环绕平滑度（默认10）

    BedroomTrigger (BoxCollider, IsTrigger)
    └── 挂一个简单脚本：
        void OnTriggerEnter(Collider other) {
            if (other.CompareTag("Player"))
                FindObjectOfType<OpeningSequence>().OnReachedBedroom();
        }

十九、HeartExchange 交心机制
================================================================================

  文件位置：Scripts/NPC/HeartExchange.cs

  使用方法：
  1. 在可交心的NPC GameObject 上挂载 HeartExchange.cs
     （公园林悦、夕台季阳飞）
  2. NPC 必须有 Collider (IsTrigger)
  3. 在 Inspector 中配置：
     - requiredItemId    → 需要交出的物品ID
       公园林悦：heart_leave（假条）
       夕台季阳飞：（空，不需要物品）
     - rewardItemId      → 交心后获得的物品ID（可选）
       公园林悦：（空）
       夕台季阳飞：（空）
     - dayRequired       → 需要的天数
       公园林悦：6
       夕台季阳飞：6
     - prerequisiteFlag   → 前置标记（可选）
       公园林悦：（空，但需要有"吉签"由NPCController控制）
     - heartEffectPrefab → 心脏特效预制体（需要自己做）
     - heartSpawnPoint   → 心脏生成位置（可选，默认NPC上方1.2m）

  自动行为：
  - 玩家进入触发区 + 满足条件时可按E触发
  - 播放：屏幕震动 + 红色色调偏移 + 暗角效果 + 心脏上升动画
  - 移除 requiredItemId
  - 给予 rewardItemId（如果有）
  - 精神值+1
  - 设置标记 "heart_exchange_{NPC名}"

  调用后检查标记：
  GameDataManager.Instance.GetFlag("heart_exchange_XXX")
